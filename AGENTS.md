# Project Agent Instructions

## Git and GitHub

- Do not perform Git or GitHub operations in this project. This includes read-only commands such as checking status or history, as well as branch, commit, fetch, pull, push, merge, tag, and GitHub-hosted actions.
- The user handles all GitHub uploads and any other Git/GitHub work.
- Work only with project files and non-Git verification unless the user explicitly changes this instruction.

## Server and Database Validation

- Do not log in to the user's servers or connect to their databases, including for validation or troubleshooting.
- When validation on a user's server is needed, provide a complete operation guide for the user to run themselves.
- Do not store server passwords, database passwords, or other credentials in this repository. Ask the user to enter credentials interactively or maintain them in a local, untracked configuration file.
